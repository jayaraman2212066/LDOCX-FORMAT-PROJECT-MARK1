v2.5.0 • Living Standard v3.0

Released October 10, 2026 • Build #1284
STABLE OPEN SPEC STANDARD
ADDED
  • • Dual-Container Standard: Modern canonical ZIP container bundling manifest.json + document.json with backward-compatible spec.json for legacy v2.0 viewers.
  • • Spatial 3D Three.js Viewports: Integrated 60 FPS WebGL orbit canvas supporting Draco-compressed geometry and material shaders.
  • • 20-Year Fallback Longevity: Bundled zero-dependency fallback.html runtime assuring long-term archival accessibility.
IMPROVED
  • • Zero Text Drift Engine: Upgraded LdocTextLayout off-DOM arithmetic layout, achieving 25/25 verified bit-for-bit parity across Editor, Viewer, and headless PDF flattener.
  • • Magazine-Style Obstacle Exclusion: Text paragraphs dynamically wrap around 3D canvases using geometric boundary carving.
SECURITY
  • • Ed25519 Cryptographic Root Signing: Built-in SHA-256 Merkle tree manifest detects tampering in <15ms with block-level error isolation.
FIXED
  • • WebKit Soft-Hyphen Loop Guard: Hardened line-breaking cursor advance against zero-width syllabic loops in Safari / WebKit.
