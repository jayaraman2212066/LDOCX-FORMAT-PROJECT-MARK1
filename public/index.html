FREQUENTLY ASKED QUESTIONS

Common Questions & Direct Answers

How does .ldocx differ fundamentally from a PDF file? +
PDF was designed in 1993 for printer paper output. It uses static postscript glyph coordinates without reflow capability. .ldocx files are living software containers holding a reactive AST, 3D spatial models, and Pretext arithmetic typography that adapts dynamically while guaranteeing bit-for-bit text layout consistency.
Can LDOC Studio run completely disconnected in air-gapped SCIF environments? +
Yes. LDOC Studio is 100% self-contained. All WebGL shaders, Three.js runtimes, Math engines, and Pretext layout metrics are bundled locally. Zero external network requests are made, guaranteeing compliance with military, banking, and confidential R&D requirements.
Is the Studio Pro license a recurring monthly fee? +
No. LDOC Studio Pro is a one-time $19 purchase for a perpetual, lifetime workstation license with zero recurring subscription charges.
How does Merkle cryptographic verification work? +
Every block, paragraph, and 3D mesh is hashed into a SHA-256 Merkle tree signed with the author's Ed25519 digital key. Opening a document validates the entire tree in <15ms. If even a single byte or CAD vertex has been tampered with, an instant alarm is triggered.
