# LDOC Showcase

## Location

```
ldoc-core/examples/ldoc-showcase.ldocx
```

## Commands

### Validate
```
ldoc validate ldoc-core\examples\ldoc-showcase.ldocx
```

### Inspect
```
ldoc inspect ldoc-core\examples\ldoc-showcase.ldocx
```

### View
```
ldoc view ldoc-core\examples\ldoc-showcase.ldocx
```

## Generation

The showcase is generated by `ldoc pack-dynamic` using `DynamicDocumentBuilder`. It is a genuine `.ldocx` file — not a static HTML mockup.

To regenerate:
```
ldoc pack-dynamic
```
