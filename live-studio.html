Build, Parse & Automate with @ldoc/sdk

The decoupled open-source @ldoc/sdk gives developers programmatic control to generate living documents in CI/CD pipelines, extract structured AST data, validate against Schema 2.5.0, and verify SHA-256 integrity checksums.

  • ✓ Zero UI dependencies — clean, lightweight, works in Node & Edge
  • ✓ Full Round-Trip ZIP Serialization & Cryptographic Checksumming
  • ✓ Canonical JSON Schema 2.5.0 Enforcement

import { parse, serialize, validate } from '@ldoc/sdk';
import fs from 'fs';

// 1. Parse .ldocx container
const buffer = fs.readFileSync('report.ldocx');
const doc = await parse(buffer);

// 2. Inject reactive Python chart block
doc.pages[0].blocks.push({
  type: 'chart',
  title: 'Q3 Financial Telemetry',
  data: [14.2, 18.9, 24.5]
});

// 3. Validate and re-serialize with SHA-256
validate(doc);
const compiled = await serialize(doc);
fs.writeFileSync('audited_report.ldocx', compiled);
console.log('✓ Living Document serialized successfully!');
